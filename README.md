# QuizMaster
QuizMaster is a Java-based console quiz application that tests the user's general knowledge through multiple-choice questions.
## Features
- 50 General Knowledge questions
- 10 questions per quiz
- Multiple-choice options (A, B, C, D)
- Randomized questions
- No repeated questions across quiz attempts
- Automatic question pool reset
- Instant correct/wrong answer feedback
- Score calculation
- Performance feedback
- Replay option

## Technologies Used
- Java
- VS Code
- Java Scanner
- Arrays
- ArrayList
- Random selection

## How to Run
1. Open the project in VS Code.
2. Open `Main.java`.
3. Run the program.
4. Answer each question using A, B, C, or D.
5. View your score at the end of the quiz.
